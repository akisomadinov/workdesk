# Участие в разработке

Для разработки нужны .NET 10, Node.js 24, Corepack/Yarn 4. Для интеграционных тестов очереди нужен Redis. Начни с README.md и docs/ARCHITECTURE.md.

Перед отправкой изменений выполни `dotnet test` и `cd client && corepack yarn build`. Генерируемые RTK hooks обновляются через `corepack yarn generate-api` при запущенном backend. Файлы `src/api/autogen/` вручную не редактируются.

Изменения схемы сопровождаются EF-миграцией. Изменения доступа, приглашений, очереди и повторов уведомлений сопровождаются проверками на сервере. Не добавляй токены, локальные базы, экспорты документов, ключи и содержимое `.secrets/` в коммиты.

В issue или PR укажи сценарий, ожидаемое поведение и способ проверки. Уязвимости сообщай по SECURITY.md, без публичного раскрытия рабочих данных.
